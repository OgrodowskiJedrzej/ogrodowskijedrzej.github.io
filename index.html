About

Curiosity is the starting point.

I’m interested in ML systems, research engineering, and infrastructure, especially how to build reliable systems that are easy to monitor and scale. My experience in R&D teams has shaped my interest in helping researchers build efficient pipelines. I enjoy working with HPC, where I spend much of my time making GPUs go brrrr. Recently, I’ve also been exploring agentic coding and how it changes the way we build software, especially how to build custom agents and harness them.

In 2026, I was a Robotics Summer Scholar at Carnegie Mellon University, and I’ve continued collaborating with the lab since then. My work focuses on vision models and adapting foundation models with fewer labels for the DARPA Triage Challenge. Before that, I was a machine learning intern at Demant, a hearing healthcare company, where I helped build systems for hearing aids.

I’m a fourth-year Computer Science student. My thesis explores efficient knowledge distillation for segmentation models, focusing on methods that work across different model architectures.

Beyond the technical side, I’m organizing the best ML conference in Poland and coordinate activities in GHOST student club.

Selected projects

AI Infrastructure

Distributed inference on Kubernetes

I explore how to design and benchmark distributed inference systems on Kubernetes using vLLM for model serving and llm-d for load-aware routing. I implemented common mechanisms like KV-cache offloading, prefix caching, and scaling with KEDA. I also built a Go API gateway with Redis-backed rate limiting and integrated Prometheus, Grafana, and Loki to measure performance and investigate system behavior.

In progress

ML Systems

Optimized resource allocation on Tenstorrent Blackhole

I research how to design reliable kernels and kernel fusions to reduce hardware communication time and model inference time. I am building an MLOps platform using Prometheus, Weights&Biases, and the Tenstorrent stack to help the team evaluate our approaches.

In progress

AI Infrastructure

Cloud infrastructure with Terraform

I developed Terraform configuration to quickly set up an ML training pipeline on Microsoft Azure. This made it easier to repeat the setup across Azure subscriptions.
